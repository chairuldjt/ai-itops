# Connect your tools

The gateway uses the standard **OpenAI format**, so any tool that works with OpenAI can be pointed at the gateway with no code changes.

You only need two things:

- **Base URL:** `https://your-domain.com/v1`
- **API key:** `sk_live_YOUR_KEY` (created in the console)

## opencode (CLI)

Create or edit `~/.config/opencode/config.json`:

```json
{
  "providers": {
    "aigateway": {
      "type": "openai",
      "baseURL": "https://your-domain.com/v1",
      "apiKey": "sk_live_YOUR_KEY"
    }
  }
}
```

Then run:

```bash
opencode --provider aigateway
```

## Cursor

1. Open **Cursor Settings → Models**
2. Click **+ Add model** and enter a model name from the [Models](/models) page
3. Set **API Base URL** to `https://your-domain.com/v1`
4. Paste your API key and set it as default

## Python (OpenAI SDK)

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://your-domain.com/v1",
    api_key="sk_live_YOUR_KEY"
)

response = client.chat.completions.create(
    model="MODEL_NAME",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

## Node.js (OpenAI SDK)

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://your-domain.com/v1",
  apiKey: "sk_live_YOUR_KEY",
});

const response = await client.chat.completions.create({
  model: "MODEL_NAME",
  messages: [{ role: "user", content: "Hello!" }],
});

console.log(response.choices[0].message.content);
```

## Available endpoints

| Endpoint | What it does |
|----------|--------------|
| `POST /v1/chat/completions` | Chat with a model (streaming or not) |
| `GET /v1/models` | List the models you can use |
