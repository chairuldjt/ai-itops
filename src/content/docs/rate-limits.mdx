# Usage & limits

You pay for what you use. This page explains how credits work and what limits apply.

## Credits & balance

- Your account has a **credit balance** (in USD).
- Every request costs a small amount based on the model and how many tokens it uses.
- The cost is deducted from your balance automatically after each request.

You can see your balance at any time in the console under **Billing**, and top up when it runs low.

## What happens when you run out

If your balance reaches zero, new requests are blocked until you top up. You'll get a clear error telling you to add credit:

```json
{
  "error": {
    "message": "Insufficient credit balance. Please top up to continue.",
    "type": "billing_error",
    "code": "insufficient_balance"
  }
}
```

## Rate limits

To keep things fair, each API key can make a limited number of requests per minute. If you go too fast, you'll briefly be asked to slow down:

```json
{
  "error": {
    "message": "Rate limit exceeded. Try again later.",
    "type": "rate_limit_error",
    "code": "rate_limit_exceeded"
  }
}
```

Just wait a moment and try again.

## Tracking your usage

Open **Usage** in the console to see every request, including:

- The model used
- Tokens consumed
- Cost
- Whether it succeeded

## Tips

- **Watch your balance** — top up before it hits zero to avoid interruptions.
- **Use the right model** — cheaper models cost less per request.
- **Check Usage** — spot anything unexpected early.
