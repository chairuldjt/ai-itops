# Management API

The Management API lets you manage your gateway programmatically — create users, issue keys, configure models, and more.

<Callout type="warning">
  The Management API requires admin authentication. Keep your admin credentials secure.
</Callout>

## Authentication

Use your admin API key:

```
Authorization: Bearer admin_sk_YOUR_KEY
```

## Endpoints

### List models

```http
GET /admin/v1/models
```

Response:

```json
{
  "models": [
    {
      "id": "gpt-4o",
      "upstream_model": "gpt-4o",
      "capabilities": ["vision", "streaming", "tools"],
      "image_policy": "strip_and_instruct",
      "input_cost_per_1k": 0.005,
      "output_cost_per_1k": 0.015
    }
  ]
}
```

### Create a model

```http
POST /admin/v1/models
Content-Type: application/json
```

```json
{
  "id": "claude-sonnet-4-20250514",
  "upstream_model": "claude-sonnet-4-20250514",
  "capabilities": ["vision", "streaming", "tools"],
  "image_policy": "strip_and_instruct",
  "input_cost_per_1k": 0.003,
  "output_cost_per_1k": 0.015
}
```

### Update a model

```http
PATCH /admin/v1/models/:id
Content-Type: application/json
```

```json
{
  "image_policy": "canned_response",
  "input_cost_per_1k": 0.004
}
```

### Delete a model

```http
DELETE /admin/v1/models/:id
```

### List users

```http
GET /admin/v1/users
```

### Issue an API key

```http
POST /admin/v1/keys
Content-Type: application/json
```

```json
{
  "user_id": "user_abc123",
  "name": "Production key",
  "credit_limit": 10.00
}
```

### Revoke an API key

```http
DELETE /admin/v1/keys/:key_id
```

### Top up credits

```http
POST /admin/v1/users/:user_id/topup
Content-Type: application/json
```

```json
{
  "amount": 25.00,
  "description": "Monthly top-up"
}
```

## Rate limits

The Management API has its own rate limits:

- **100 requests/minute** per admin key
- **Burst:** up to 20 requests/second

## Error handling

```json
{
  "error": {
    "message": "Model not found",
    "type": "not_found_error",
    "code": "model_not_found"
  }
}
```
