# FAQ

## General

### What is AI Gateway?

AI Gateway is a unified AI model hub that converts leading LLMs into OpenAI and Anthropic compatible APIs. One API key unlocks your entire model catalog.

### How is this different from OpenAI's API?

AI Gateway sits in front of your own model fleet (via 9router). You control the models, pricing, and policies. It's your own AI API, not a reselling service.

### Is there a free tier?

Yes. New accounts get free credits. No credit card required to start.

## API & Integration

### Which endpoints are supported?

- OpenAI: `/v1/chat/completions`, `/v1/models`
- Anthropic: `/anthropic/v1/messages`

### Does streaming work?

Yes. Full SSE streaming passthrough for both OpenAI and Anthropic formats.

### Can I use tool/function calling?

Yes, if the upstream model supports it. The gateway passes tool calls through transparently.

## Models

### How do I add a new model?

Use the admin panel under **Admin → Models**, or use the [Management API](/docs/management-api).

### Can I set custom pricing?

Yes. Each model has `input_cost_per_1k` and `output_cost_per_1k` in micro-USD.

### What happens if I send an image to a text-only model?

The gateway applies the model's **image policy**. By default, it strips the image and the model replies naturally. See [Capability Handling](/docs/capability-handling).

## Billing

### How does credit deduction work?

Credits are deducted per request based on token usage and the model's cost settings. Deduction happens after the response is complete.

### What happens when my credits run out?

Requests return `402 Payment Required`. Top up via the dashboard or admin API.

### Can I set a monthly budget?

Yes. Set a per-user monthly budget in the dashboard or via the Management API.

## Troubleshooting

### I get `401 Unauthorized`

Check that your API key is correct and not revoked. Ensure the `Authorization` header format is `Bearer sk_live_YOUR_KEY`.

### I get `404 Not Found`

Verify your base URL:
- OpenAI: `https://your-domain.com/v1`
- Anthropic: `https://your-domain.com/anthropic/v1`

### I get `429 Too Many Requests`

You've hit a rate limit. Wait for the `retry_after` period, or upgrade your tier.

### The model I need isn't listed

Add it in the admin panel. You'll need the upstream model ID and a public name.
