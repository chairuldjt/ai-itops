# FAQ

## General

### What is AI Gateway?

AI Gateway gives you one API key that works with many AI models. Instead of signing up for each provider separately, you use a single endpoint and a single key.

### Do I need a different key for each model?

No. One API key works with every model in the catalog. You just change the model name in your request.

### Is there a free trial?

New accounts may receive starter credits. Check your balance in the console under **Billing**.

## Using the API

### Which endpoint do I use?

Send requests to `POST /v1/chat/completions` and list models with `GET /v1/models`. See [Connect your tools](/docs/openai-setup).

### Does streaming work?

Yes. Add `"stream": true` to your request to get the answer as it's generated.

### Can I use tools / function calling?

Yes, for models that support it. Tool calls are passed through automatically.

## Billing

### How am I charged?

Each request costs a small amount based on the model and the number of tokens used. The cost is deducted from your balance automatically.

### What happens when my balance runs out?

New requests are blocked until you top up. You'll see a clear message telling you to add credit.

### Where do I see my spending?

Open **Usage** in the console to see every request and its cost, or **Billing** for your balance.

## Troubleshooting

### I get `401 Unauthorized`

Check that your API key is correct and that the header is formatted as `Authorization: Bearer sk_live_YOUR_KEY`.

### I get `404 Not Found`

Make sure your base URL is `https://your-domain.com/v1` and that the model name exists on the [Models](/models) page.

### I get `402 Payment Required`

Your balance is empty. Top up in the console under **Billing**.

### I get `429 Too Many Requests`

You're sending requests too quickly. Wait a moment and try again.
