# Quickstart

Get your first AI response working in under 5 minutes.

## Step 1 — Create an account

Go to the **Sign up** page and create your account.

## Step 2 — Top up your balance

Add credit to your account so you can pay for usage. Go to **Billing** in the console to top up.

## Step 3 — Create your API key

In the console, open **API Keys** and create a new key. It looks like this:

```
sk_live_YOUR_KEY_HERE
```

<Callout type="warning">
  Your key is shown only once — copy it right away and keep it secret. Never
  share it or commit it to code repositories.
</Callout>

## Step 4 — Make your first request

Use the key to ask a model a question:

```bash
curl https://your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_NAME",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

Replace `MODEL_NAME` with a model from the [Models](/models) page. You'll get a response like:

```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "choices": [{
    "message": { "role": "assistant", "content": "Hello! How can I help?" },
    "finish_reason": "stop"
  }],
  "usage": { "prompt_tokens": 10, "completion_tokens": 8, "total_tokens": 18 }
}
```

## Step 5 — See your usage

Open **Usage** in the console to see the request, the tokens it used, and the cost.
