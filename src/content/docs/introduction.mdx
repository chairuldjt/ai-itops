# Introduction

Welcome! AI Gateway gives you **one API key for many AI models**. Instead of signing up for each AI provider separately, you use a single key and a single endpoint to access every model in the catalog.

## What you get

- **One key, many models** — a single API key works with every model we offer.
- **Works with your tools** — compatible with the OpenAI format, so it plugs into OpenAI SDK, opencode, Cursor, Windsurf, and more.
- **Pay as you go** — top up a credit balance and only pay for what you actually use.
- **See your usage** — every request is tracked, with tokens and cost clearly shown.

## How it works

1. **Create an account** and top up your balance.
2. **Create an API key** from the console.
3. **Point your app or tool** at the gateway using your key.
4. **Start calling any model** — usage is metered automatically.

That's it. No per-provider setup, no juggling multiple keys.
