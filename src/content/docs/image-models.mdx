# Image Models

AI Gateway supports vision-capable models and handles images gracefully even for text-only models.

## How vision works

When a client sends an image (as a URL or base64 data) in a chat completion request, the gateway checks whether the target model supports vision.

### Vision-capable models

Images pass through to the upstream model as-is. No transformation needed.

### Non-vision models

When a text-only model receives an image, the gateway applies the model's **image policy** instead of returning an error.

## Sending images

### OpenAI format

```json
{
  "model": "gpt-4o",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "What's in this image?" },
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/image.png" }
      }
    ]
  }]
}
```

### Base64 images

```json
{
  "model": "gpt-4o",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "Describe this image" },
      {
        "type": "image_url",
        "image_url": {
          "url": "data:image/png;base64,iVBORw0KGgo..."
        }
      }
    ]
  }]
}
```

## Capability declaration

In the admin panel, each model declares its capabilities:

| Capability | Description |
|-----------|-------------|
| `vision` | Model can process images |
| `streaming` | Model supports SSE streaming |
| `tools` | Model supports function/tool calling |
