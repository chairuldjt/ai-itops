# Privacy Policy

*Last updated: January 2026*

## Data we collect

### Account data

- Email address and name (for authentication)
- Payment information (processed by our payment provider, never stored on our servers)

### API usage data

- Request/response logs (retained for 30 days)
- Token counts and model usage
- IP addresses (for abuse prevention)

### What we do NOT collect

- **Prompt content** — we do not store or inspect the content of your API requests
- **Response content** — we do not log response bodies
- **Images and files** — we do not store any media sent through the API

## How we use your data

| Data type | Purpose |
|-----------|---------|
| Account data | Authentication, billing, support |
| Usage data | Billing, rate limiting, abuse prevention |
| Request logs | Debugging, performance monitoring (anonymized) |

## Data storage

- All data is stored in encrypted databases
- API keys are hashed — we cannot recover them
- Logs are automatically purged after 30 days

## Third parties

We do not sell your data. We use:

- **Payment provider** — for processing payments
- **Infrastructure provider** — for hosting (data stays within the provider's region)

## Your rights

- **Export** — request a copy of your account data
- **Delete** — request account deletion and data removal
- **Opt-out** — opt out of non-essential data collection

## Contact

For privacy-related questions, contact: `privacy@your-domain.com`
